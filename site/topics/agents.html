Agents & agentic systems

Last updated: 2026-09-22

Current state

Today the harness argument got the number it has been missing. AWS’s Strands Harness (Sep 21) runs Claude Fable 5 on Terminal-Bench 2.1 for $56.29 against Claude Code’s $248.05 while scoring 69.7 against 61.8 — better and roughly four times cheaper — with DeepSeek Harness at $40.30 and 59.5 marking where the saving stops being free. The attributed cause is deliberately unglamorous: tool output truncated at 1,500 tokens, compaction at 85% of the window. Put beside the harness-tax study, which found Claude Code opening a session with more than 27,000 tokens of context against Pi’s 2,000, the two agree on a conclusion this page resisted for months: the harness is mostly a context-management policy, and that policy is priced.

The other two arrivals are both about who owns the surface rather than what runs on it. Meta opened Muse connectors to outside developers — you bring an API and a description, Meta brings the agent, the browser and the user context, plus a functional, security and legal review before a connector is findable and an editorial decision about which get featured. Google open-sourced AX, a declarative orchestrator that sandboxes, wires and fences agent workloads on a cluster on top of Agent Substrate, and describes the experience as close to Kubernetes. One is an app store, the other a scheduler; both assume agent runs are now numerous and uniform enough to need infrastructure built for their shape rather than per-application glue.

Today’s cycle’s clearest result is also its smallest intervention. Meta AI’s Proactive Memory Agent runs a second model beside the action agent, keeps notes from its eight most recent outputs — facts, environment details, fixes that worked, commands that failed — and at each step injects either nothing or one short reminder. On Terminal-Bench 2.0 that moved Claude Sonnet 4.5 from 37.6% to 45.9% and Opus 4.6 from 43.5% to 45.9%; on τ2-Bench, Sonnet from 55.0% to 61.8%. The control is what makes it a finding rather than a prompting trick: reminding at every step did worse than letting the memory agent pick the moment, which says the deficit being repaired is attention allocation, not lost context. It needs no retraining, so it bolts onto an existing agent — and the gains shrink on the stronger action model, which is the number to watch if the effect is partly covering for weaker instruction-following.

Two agents shipped this week with opposite answers to the question of whose authority an agent acts under. Google’s family agent gets its own cloud computer and its own Google account, serving up to six people from a household’s shared mail, files and calendars and asking permission before acting outside the group — the permission boundary becomes a property of the account. Meta’s Muse for Mac takes the other route, borrowing the user’s own access to files, mail, messages, calendar and notes, with opt-in scopes, approval gates on deletes and sends, and a secure VM — qualified by the clause that Meta can still reach the data when needed to operate the service. The pairing matters because this week’s OpenAI breach showed exactly what a borrowed identity costs: one hijacked employee session reached the internal monorepo because the agent carried the connectors.

The browser loop got faster and got its boundary in the same week. Browser Use’s jev-ultrafast hands the choice of operation and target to Jev and calls a text model only when something must be typed, finding a Google Flights itinerary in 7.073 seconds across 17 requests at a median 178ms. The premise is that most steps in a browser trajectory are selections among visible options, not judgements about the page — and Context7 measured where that stops holding, with the same model at 27% against 93% on crawl-root selection while running 10–170× faster. Alongside, Agora proposes an append-only Git DAG as the exchange format for research agents, making every hypothesis, result and verification a commit with a parent and a hash. It ships with no throughput or quality numbers, so it offers a provenance argument rather than evidence that agents coordinate better through it.

Earlier cycles

Today's cycle is about the protocol becoming the thing platforms publish rather than the thing agents load. Google opened early access to an MCP server for Google Home, letting an outside agent such as ChatGPT control the whole device ecosystem — gated behind a Google Cloud project and a US Premium Advanced subscription, but a consumer platform exposing its control surface as MCP rather than as a partner integration all the same. Stanford's Paper2Agent does it to the literature, reading a paper with its repository and emitting a tested MCP server: 22 tools for the AlphaGenome agent in about 45 minutes for US $14, and 74 of 100 bioRxiv papers converted. The auditing question changes shape with them. It is no longer which servers an agent has loaded, but what a platform lets any connected agent do — and Google Home answers that with a house.

The counterweight arrives at the tool-call boundary. Agent-net's Webagent (Sep 14, Apache 2.0, v0) turns a website into an agent from one JSON spec with nine pluggable slots, and routes every call through action.Guard before it runs — the permission check as a structural property of the harness rather than a sentence in a prompt. Google's Agent Anomaly Detection (private preview) takes the after-the-fact position instead, watching deployed agents for anomalies in the logs and traces the platform already collects; free at runtime, and blind to whatever the harness did not record. Tencent's BrowserSkill (3.5k stars) shows what gets traded when neither is available: it drives a separate window against the user's already-logged-in browser profile, handing back control for CAPTCHAs, which solves the authentication problem that defeats computer-use agents on real sites by borrowing the user's whole identity for the duration.

The prior cycle was about supervision, and it arrived with the first honest price tag on running agents in bulk. Nous Research refactored Hermes with 1,393 agents for roughly $19,000 in tokens and published the procedure rather than the headline: plan, shard carefully, review every shard, reconcile conflicts, and expect strange breakage when hundreds of workers touch one repository. That last clause names a failure this page has not previously had a case study for — not an agent going wrong, but many agents each being correct about overlapping parts of the same codebase, which neither the channel designs nor the fixed-pipeline designs below reconcile. A circulated Codex pattern supplies the cheap counterpart: Astra orchestrates, Sol and Luna execute, and a 15-minute heartbeat inspects progress mid-run and corrects drift before the workers finish, which is supervision in flight against Foreman's inspection at the end. Cognition's Devin Fusion takes the same instinct into model choice, keeping a frontier model as lead that plans, reviews and can reclaim control, while a cheaper model executes — explicitly not a one-shot router, because a routing decision made before the work starts has no recovery path when it is wrong. None of the three has published the parameter that decides whether it pays: no measured heartbeat interval, no comparative figures for Fusion, and $19K as a floor for swarm work rather than a result.

The prior cycle turned the harness thesis into two pieces of buildable instruction, which is the point at which an argument stops being a position. LangChain's Sydney Runkle published the build order (Sep 15): start bare with create_agent running the loop over a model, a few tools and a prompt; add middleware, defined as everything a prompt cannot do — trimming context before it overruns, retrying failed tools, redacting sensitive data, pausing for human review, capping spend; then fit the harness to the specific task rather than building one generic wrapper. That middle list is the section's own failure catalogue named as a standard layer, which is what converts “the harness is the product” from an observation into an interface with a quickstart behind it. Google Cloud supplied the orchestration half the same day, and its routing rule improves on the one in general use: Gemini 3.8 Flash does routine work, and anything harder or irreversible escalates to Claude Fable 5.1. Cost tiering splits on guessed difficulty; reversibility is a property of the action the harness can read before the call, and it puts the expensive model exactly where a mistake cannot be undone.

If the harness is the product, the prior cycle shows who is buying it and where the seams are. Garry Tan reports that almost every non-hardware startup at Y Combinator's latest demo day is building a domain-specific harness — the tools, files, memory and completion logic wrapped around a model — on the bet that encoding how a job is actually done in one industry survives swapping the model underneath. One investor's read of one batch is not a measurement, but it lines up with what OpenAI, Anthropic and LangChain each shipped this month, and it names the layer the money is moving to. At the consumer end, Apple built the same swap into Siri: Model Delegation lets Claude register as a Siri extension exactly as ChatGPT already does, with the delegated model handing tasks back whenever a request needs an Apple system feature, and a separate inference-provider option can replace Apple's own server-side Siri model entirely. The hand-back boundary is the design worth studying — the third-party model gets the reasoning, the platform keeps everything that touches the device.

The harness stopped being something you assemble and became something you buy. OpenAI's Agents API (Sep 11, public beta) sells the managed scaffolding behind Codex directly: one call launches an agent with its own compute environment, files, tools, MCP servers and up to three concurrent subagents, carrying work across multiple context windows, compacting stale context on its own, discovering tools only when they are needed, and composing tool results in code rather than returning every intermediate result to the model. There is no platform fee — you pay for models and tools — and it runs in OpenAI's sandbox, on your own infrastructure, or via Vercel and Cloudflare. That is the layer this page has spent a year describing as separate from the model, now priced separately from it. Cursor Projects the same day takes the coordinator further up: a persistent agent holding months of context, delegating to thousands of subagents, and starting work from a Slack message, a schedule or a pull request rather than a prompt, with Cursor reporting 30% more merged PRs for new users and six times as many for people who work primarily through it — vendor figures that count merges, not correctness.

The counterweight this cycle is about what a long agent run leaves behind. Simon Willison gave ChatGPT Work with GPT-6 Astra a single sentence — 5K and 10K running loops from his house, using OpenStreetMap — and got back exactly that after 27 minutes: address resolved through Nominatim, roads and trails pulled through Overpass, loops computed locally, results returned as an embedded D3 map plus GPX and GeoJSON. The code that did it was never visible in the UI, and by the time he asked for it the thread had compacted and it was gone. That is a harness defect with a specific fix, which he states plainly: a system that compacts must preserve the pre-compaction text and expose it through a tool call. It sits directly against SelfCompact below, which improved when to compact; nobody has yet made compaction non-destructive to the record of what the agent did, and a 27-minute run whose working cannot be recovered is not a reproducible result.

Two counterweights landed beside them. Google scored thousands of submissions to its agents challenge and found the surviving patterns were unglamorous: bidirectional MCP, event-driven concurrency, validating fallback-model output exactly as strictly as the primary's, and cheap routing ahead of expensive calls, with one team serving over 40% of requests from a zero-token regex layer — the strongest “multi-agent” systems distinguished by engineering rather than by agent count. And SelfCompact (Johns Hopkins and Apple) shows how much of the compaction problem is criteria rather than machinery: a probe firing every 16,000 tokens asks the model to judge its own state against an explicit rubric — compact after a finished sub-task, never mid-step — lifting Qwen3-30B-A3B on IMO-Answerbench to 52.1% against 48.7% for fixed-interval summarisation and 45.2% for none, with no fine-tuning; swap the rubric for a bare “do you want to compact?” and the gain vanishes. AWS's open-source Pizza Bot supplies the missing interface for all of this, treating a background agent's output as an inbox — finished work in Unread, work awaiting approval in Action, on-disk checkpoints so a closed tab does not end a task.

Before this cycle, the gap the extension standard left open got its first managed answer, and one arrival put a governor on the thing agents actually overrun. LangChain's Connections (Sep 10) makes explicit a distinction harnesses have been leaving implicit: an agent-owned secret used on everyone's behalf, appropriate for a web search, against a user-owned OAuth grant borrowed for the duration of one caller's request, appropriate for filing a ticket as the person who asked. Per-caller identity is what makes the second case auditable instead of a shared service account with a name pasted into the prompt. Hugging Face's autonomous ML engineer (Sep 10), running literature research, dataset construction and training through to a published demo from a plain-English brief, is notable for the same reason in a different register: each run gets its own dashboard, and the user sets a compute budget the agent is held to. Long-running agents that train things are the class where cost failure stays silent until the invoice, and treating the budget as part of the task specification rather than as after-the-fact monitoring is the first mainstream attempt to bound it. Both are about authority and limits rather than capability, which is where the portability work stopped.

Agent Plugins 1.0 (Aug 13–14) put native Agent Skills and MCP configuration in one predictable directory and manifest so a plugin built once loads in any compatible client, with client-specific features quarantined in namespaced folders and installation, permissions and trust left to each client — standardising what an agent can do while leaving untouched what it may reach, the same seam the role-confusion account of prompt injection names as the actual failure. Two results the same week move attention from capability to loop design. Foreman runs each task through Classifier, Analyst, Implementer and Reviewer stations and returns a reviewed draft pull request, with the Reviewer judging the real diff from fresh context rather than grading the plan it was handed — the concrete form of the argument that the best verifier is an agent that did not write the code. And a genetic search over agent designs cut a CLI's startup from 142.0ms to 98.6ms with a variant that did not exist when the search began, kept honest by binary gates that discard broken candidates and a numeric rubric frozen before any results appeared. Both substitute measurement for intuition about agent structure, which is the direction the memory strand has been forced in as well: re-running memory-based agents across shuffled task orders shows much of their reported self-improvement is evaluation noise and sequencing rather than learning.

Before that, the consumer agent had arrived with an isolation model attached. Meta's Muse (Sep 9) gives every user a persistent agent with its own cloud computer and browser that keeps running after the app closes, and pairs it with a separate Sentinel agent inspecting everything leaving the VM, hiding passwords from Muse itself and gating sensitive actions behind approval — the egress check sitting outside the agent being checked, which is the whole product. Ben Dicken's case for database-backed memory pushed the other way, toward less machinery: Postgres or SQLite plus views, scoped credentials, result caps and short timeouts already supplies the governance that was the real bottleneck, and agents are already fluent in SQL. A proposed policy algebra put a price on continuous enforcement — 94.8% of rule-breaking actions stopped or corrected, 86.9% of legitimate ones completed — so one legitimate task in eight is what it currently costs.

Standards and incumbents moved on the same axis. The MCP roadmap puts progressive tool discovery and a single tool-result contract at the top of its list — the first fixes the “100 tools in context before anyone asks anything” tax, the second gives client authors one shape to build against — though it is a prioritization document, not a spec. Anthropic folded computer use, browser access, versioned skills and reusable files into one production surface, so a procedure is uploaded once, version-pinned, and reused by file ID; its availability language is inconsistent between the dated announcement and cached docs, so it should be verified per account. Slack Code put agent diffs and live previews inside team channels on every plan, making the incumbent's version of the bet that Switch, AgentConnect and Concord made first. Cursor's cloud agents gained event subscriptions, per-VM subagents and the ability to be steered mid-run without interruption, and OneCLI generalized Vercel Connect's credential model to a whole harness: a sandboxed agent per employee, a gateway that injects credentials so the agent never holds them, an outbound-only runner with no inbound ports. Google Cloud's five long-horizon agent patterns — stable prefixes, background learning, persistent workspaces, explicit failures, guard chains — are the most quietly useful item of the set, because they target the bugs that never raise an error: burnt cache, lost memory, wiped tools, a timed-out sub-agent marked done.

Underneath all of it, the harness is still openly claimed to be the higher-leverage layer. A Y Combinator talk this week argued that improving the scaffolding around a model — tools, memory, integrations — moves reasoning scores further than upgrading the model does, with some harnesses rewriting their own code; that is a claim rather than a measurement, but it lands in the same place as the 99.9%-versus-62.7% ARC-AGI-3 gap that came from harness design rather than weights. Two releases push the opposite way from framework accretion: hip-agent reduces the loop to about 200 lines of Python by making configuration environment variables, actions shell commands and a subagent a child process, and Headlong fits an entire microharness into under 10,000 lines of Bash while inverting the request/response shape — its agent keeps thinking, and messages are observations it may or may not answer. Below the harness, routing moved up a level: AgentSky puts Claude Code, Codex, Hermes, DeepSeek Harness, Kimi Code and opencode behind one API where the agent and the model are chosen in the same request, and Monid does it for tools, 1,700+ of them with the price visible before the agent commits. Alongside them, three projects — SandboxAQ's Switch, AgentConnect and Concord — all bet that agents belong in the team's existing chat rather than in a coordination layer of their own, replacing the current default of writing to a shared file and hoping. On memory, Memoryfields keeps agent state as Markdown files with YAML metadata over a SQLite vector index, and Google's WikiSkill co-evolves reusable skills with a persistent wiki built from past runs; and Browser Use adopted WebMCP, so a cooperating site hands the agent its actions instead of making it recover them from pixels.

Multi-agent tooling caught up with multi-agent ambition last month. Hermes Agent v0.21.0 shipped the plumbing that breaks first when several agents genuinely run together — bot-to-bot messaging across gateways, cron with continuity, JSON schema validation, and, most usefully, live steering of delegated subagents mid-run, which closes the gap left when delegation went asynchronous in June and a parent could dispatch work but not correct it without killing the child. OpenClaw 2.0 added the human counterpart: shared cloud sessions, so a second person can join or take over a live run without losing context — handover having been the unexamined gap in long-running agent work, where state lived in one operator's session.

September adds a genuine disagreement about harness design. A detailed architecture post argues that unavoidable complexity should be absorbed by core abstractions rather than pushed onto extensions and users — close to the opposite of DeepSeek Harness's plugin-everything posture, where models, tools, skills, sessions, sandboxes, storage, loops and scheduling are all swappable. Both ship working systems, so this is a live argument rather than a theoretical one. Alongside it, funes pushes on ownership: a durable memory layer carrying session history across machines and across agents — Claude Code, Codex, pi and Hermes against one local store — on the reasoning that if the harness is commoditizing and the model is rented, accumulated context is the asset a developer actually keeps, and it should not live inside one vendor's session format.

August's two contributions both attack the same constraint from opposite ends — what an agent carries and what it runs inside. On context, Xiaohongshu's Self-GC replaces fixed compaction rules with a planner model that decides per item whether to keep it, fold it into storage with a restorable pointer, mask its repetitive middle, or prune it outright, triggering at 30% context fill and applying a plan only when it saves 30% of tokens. It deliberately removes less than rule-based compaction (43.95% of tokens against 61.90–69.87%) and preserves later-needed detail far more often (84.85% against 54.55–69.70%) — the first quantified statement of the trade every long-running agent makes between cost and forgetting, though the authors measured retention, not output quality. On the harness, DeepSeek open-sourced the scaffolding its own benchmarks ran in (MIT, model-agnostic, plugin kernel), which does more for the harness-commoditization argument below than any essay: DeepSeek-V4-Pro-0813 scores 87.9% on Terminal-Bench 2.1 in DeepSeek Harness's minimal mode, 78.7% on Terminus 2, and 54.68% on Vals AI's — a 33-point spread on one checkpoint, which is the scale of the scaffolding contribution nobody else publishes.

Two July 31 signals push agents toward richer context and a bigger surface. On context: an enterprise-data thread argues most organizations don’t have a model problem, they have a context problem — even the best LLM can’t personalize an experience, detect fraud, or make intelligent recommendations if it doesn’t know what the customer has done, is doing right now, or what matters in the moment — and documents engineering teams wiring real-time behavioral data directly into agents via Snowplow Signals and Google’s Agent Development Kit (ADK), powering Gemini Enterprise agents with practical production architectures. On surface: Perplexity’s Personal Computer is an agentic tool that turns the operating system itself into an AI system, positioning Perplexity’s agent as a "general-purpose digital worker" — the step past terminal-native search in the OS-as-agent-surface progression this page tracks.

A fourth installment in the harness-engineering series landed July 28: Paul Iusztin's "The Bare-Bones Coding Agent Loop" strips the framework down to a minimal reference implementation — one agent loop, nine tools, and a terminal you can steer — designed to make explicit what Claude Code and Codex actually do under the hood rather than leaving their architecture as a black box. The series' third installment (also July 28) came from the other side of the pairing: Hugo Bowne-Anderson's "How to Build an Effective Agent Harness" turns his July 21 pushback into a working framework, mapping agent design along two axes — context complexity and action complexity — and naming the harness's five runtime jobs (run the reasoning loop, execute tools, assemble and manage context, persist state, enforce boundaries), illustrated with Pi, OpenClaw, Codex, and Claude Code as worked examples rather than templates to copy wholesale.

The newest thread before that (mid-to-late July) is "harness engineering" being named and argued over as a discipline in its own right. On July 21, two independent newsletters converged on the same idea from opposite ends: Decoding AI's Paul Iusztin argued that as frontier models commoditize, the harness — not the model — is what a builder actually owns, framing Claude Code, Codex, and Cursor as different harness implementations built on the same rentable frontier models; Vanishing Gradients' Hugo Bowne-Anderson pushed back against the implied prescription, arguing against overengineering the harness and that the right amount of scaffolding depends on an agent's actual action and context complexity rather than a default checklist. Iusztin continued the series July 22 with "Building a Coding Agent From Scratch," walking through designing a harness around the model — from the basic agent loop up to a remote swarm.

NVIDIA entered the same layer from the enterprise-platform side on July 21 with its Agent Toolkit, an open foundation of models, tools, skills, and a secure runtime meant to help enterprises build agents tuned to domain-specific workflows — and on July 19 extended agentic AI into vision, shipping skills such as Multi-View 3D Tracking (MV3DT) that let coding agents (Claude Code, Codex, Cursor) build full video-analytics pipelines from a plain-English prompt. On the product side, Andrew Ng released OpenWorker (July 25), an MIT-licensed, local-first desktop agent that returns finished deliverables — a polished doc, a filled spreadsheet — instead of chat replies, working across 35 app connectors while keeping data on-device; a concrete instance of the on-device/local-agent thread this page has been tracking, and of the harness question above in product form (what does a harness owe the user beyond a chat transcript).

The week's clearest theme before that is that the agent infrastructure layer is being built primitive by primitive — memory, isolation, orchestration, and observability, the four pillars of production-grade agents, all gained new building blocks at once. The most consequential is agent memory that compounds: Perplexity's Brain (June 18, in its Computer product) is the first production memory system that improves an agent's future task performance rather than just recalling user facts — every completed task feeds a context graph that Brain reviews overnight, synthesizing learnings into an auto-generated "LLM wiki" so tomorrow's runs start smarter than today's. That reframes agent memory from "remember the user" to "remember the work," and changes the ROI math for anyone running agents at scale (quality improves with use, without extra prompting). Beneath the productized layer, the open memory-framework field is still an unsettled race — Decoding AI Magazine's July 14 teardown pits Graphiti, mem0, cognee, and HydraDB against each other by building one unified memory on a single database, arguing that nobody has yet "cracked" agent memory and that each framework hides its own trade-offs. Alongside it, framework ergonomics took a notable step down in cognitive overhead with Vercel's open-source Eve (June 17), which treats an agent as just a directory of files — compiled into durable workflows with channel auth wired up automatically — making agents versionable, diffable, and one-command deployable rather than something you express as graphs or chains. Multi-agent parallelism also matured: Nous Research's Hermes async subagents (June 16) let delegated work run in the background without blocking the parent chat, removing the synchronous-delegation bottleneck in open multi-agent workflows.

These sit on top of the prior signal that the agent stack is growing upward, not outward: the contested layer is no longer the model or even the harness, but the layer above them — meta-orchestrators, governance, and multi-model fusion that compose several agents into one controllable system. Databricks' open-source Omnigent (June 13, Apache 2.0) is the clearest instance: a meta-harness that sits one level above coding agents (Claude Code, Codex, Pi, custom) to compose them into workflows, govern them with unified access control / audit logs / cost caps, and share agent configs across teams — addressing the config drift, duplicate permissions, and zero cross-agent visibility every multi-agent shop hits. That it comes from Databricks under Apache 2.0 (rather than a startup) gives it institutional weight, and it fits a broader "investment moving from base layer → control layer" trend alongside OpenRouter's Fusion (multi-model routing) and agent-isolation tooling like Bastion. This reframes the earlier harness-commoditization argument: if the single-agent harness is becoming a commodity component, the new differentiator is the orchestration and governance layer stacked on top of it.

The model/harness ends are still hardening underneath. On June 9 Anthropic released Claude Fable 5, explicitly built for long-horizon autonomy — it runs independently longer than any prior Claude, plans across stages, and verifies its own work — and shipped it with Claude Managed Agents, a managed long-running-agent harness now in public beta, plus an "advisor" pattern where cheap worker models call Fable 5 mid-task to check plans. That product move lands alongside a practitioner argument that the agentic harness itself is commoditizing into a handful of standardized, batteries-included frameworks (tools, skills, memory, sandbox, permissions) — i.e. once the harness is a component, model choice and context engineering become the differentiators. A July 8 practitioner conversation (Vanishing Gradients, on the AMP harness) pushed the same logic further: as models improve from Opus 4.8 to Fable they absorb harness features outright — AMP deleted its handoff feature once compaction got good enough — so harness code survives only if it helps inspect, verify, recover, or merge the model's work (see Tools & DevEx).

Two new threads sharpen how agents are made reliable, not just more capable. Stanford's TRACE turns an agent's recurring failures into training signal — it detects a repeated failure, auto-builds a capability-targeted RL environment around it, and trains a LoRA adapter to fix that exact gap (training detail on the Training & RL page). And a "loop engineering" discipline is being named around the plan → act → verify → repeat loop, arguing that verifiers, persistent state, and well-defined stop conditions — not one-shot prompting — are what separate an autonomous agent from one that runs until it burns the token budget. A parallel clarification effort is underway on agentic search, which practitioners note splinters into three distinct patterns (retrieval-, harness-, and model-centric). At the model layer, large open releases are now explicitly architected for long-horizon agent loops — NVIDIA's Nemotron 3 Ultra (550B/55B-active hybrid Mamba-Transformer MoE) is purpose-built for "complex, long-running agentic workflows," joining Fable 5, Opus 4.8, MiniMax M3, and Qwen3.7-Plus.

Three other currents stand out. First, retrieval is becoming agentic rather than one-shot: Google shipped an Agentic RAG framework into Gemini Enterprise (plan → rewrite → re-search until context is sufficient, +34% factuality, 90.1% cross-corpus accuracy, with a "Sufficient Context Agent" that refuses to answer on incomplete evidence), and Harness-1 is a 20B retrieval subagent trained with RL inside a stateful search harness that decides how and when to search. Second, agents keep moving on-device: alongside OpenJarvis and laptop-class Gemma 4, Kimi Work runs a native agent swarm of up to 300 parallel agents locally. Third, multi-agent orchestration continues maturing as a shippable build pattern (e.g. a six-agent Claude Code team backed by graph memory). The open ecosystem also has competitive browser computer-use agents (Microsoft Fara1.5; Kimi's WebBridge), and the agentic-data-science domain reframing continues — now extending to science with Synthetic Sciences' open-source OpenScience (Apache 2.0), a model-agnostic workbench that runs the full research loop (literature review, experimentation, paper drafting) on the researcher's own infrastructure, the first credible open equivalent of the closed "AI scientist" tools every major lab has built internally. Practitioner debate on extension patterns (MCPs vs CLIs vs skills vs custom tools) continues with no consensus winner.

The enterprise runtime for agents is now valuable enough to consolidate: on June 11 OpenAI agreed to acquire Ona — a platform supplying trusted, customer-controlled cloud environments where agent work persists across devices and lives inside enterprise systems — to fold into Codex, signaling that the secure long-running-agent execution layer is becoming a strategic asset alongside the model and the harness (see Industry & business). Two July 16 releases sharpen both ends of the harness-commoditization argument. On the runtime side, Mistral's Vibe Code Mode joins the Ona/Codex pattern with its own dedicated web surface for remote coding agents: sessions run in parallel, persist while the developer's machine is off, execute in isolated sandboxes, and connect to GitHub through to a pull request, with a new VS Code extension bringing the same agent into the IDE and a CLI /teleport command moving a live session between terminal and cloud while keeping history and approvals intact — evidence that persistent, portable remote execution is becoming a standard feature developers expect from any coding-agent vendor, not an Ona/Codex exclusive. On the harness side itself, SpaceXAI open-sourced Grok Build — the Rust terminal coding agent behind its grok CLI — under Apache 2.0: not the model, but the harness (the full-screen TUI, the agent runtime, and the tool layer for file edits and shell execution), running interactively, headlessly in scripts, or via the Agent Client Protocol. Open-sourcing the harness under a permissive license decouples the agent scaffold from Grok's weights entirely, letting anyone run xAI's exact coding-agent runtime on any model — the clearest evidence yet for the practitioner argument that the harness is hardening into a commodity, shareable component while differentiation moves to the model and the layers stacked on top of it.

Agent memory

The axis that matters is what gets remembered — the user, or the work. Three answers to where it lives: a file you can read, a wiki the agent consolidates, or the offload decision pushed into the weights (ContextPilot-14B). Judge entries on whether a human can inspect and an administrator can restrict what is stored.

Yifan Wu and colleagues at Meta AI ran a Proactive Memory Agent alongside an action agent: it maintains notes on the problem — facts, environment details such as the working directory, fixes that worked, unfinished parts, commands that failed — from the action agent’s eight most recent outputs, and at each step injects either nothing or one short reminder.
